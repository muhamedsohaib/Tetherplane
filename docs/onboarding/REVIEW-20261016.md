## Boundaries and rulings

- Continue the existing onboarding worktree. Use RELEASE-CHECKLIST as the durable
  execution ledger because the cloud skill shell helpers are not installed on Leno.
  Cost: a different bookkeeping format, with no runtime effect.
- Registry JSON state is for **one host and one IPC/network namespace**. Do not
  share it between hosts or isolated containers. Windows named pipes and Linux
  abstract Unix sockets release ownership after process exit; a distinct writer
  must fail closed while an owner is alive. Other Unix systems use a local socket
  and may need operator recovery after an abnormal exit. Node IPC reference:
  https://nodejs.org/api/net.html#ipc-support
- Pairing admission defaults to ten starts per socket source per minute, with
  1,024 tracked sources; approval defaults to twenty attempts per account per
  minute. Pending capacity is 1,024. Reverse-proxy clients share its source
  budget. Forwarded headers are not trusted. Cost: a shared proxy can throttle
  legitimate simultaneous enrollments; configure a reviewed edge limit before
  serving a larger public audience.
- Chromium teardown never targets a PID whose launcher already exited. The fresh
  private profile's browser endpoint is the shutdown authority. If that endpoint
  never appears, cleanup fails visibly and preserves the profile as evidence;
  process-tree recovery still requires operator authorization. Cost: a broken
  Chromium startup can require manual cleanup. This is a live-test blocker,
  not a successful cleanup claim.
