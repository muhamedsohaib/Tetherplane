## Non-negotiable boundaries

1. Existing MIT/Apache grants and public release tags are not retroactively revoked.
2. AGPL remains open source and permits commercial use; paying for an alternative license cannot be mandatory for uses already permitted under AGPL or prior MIT/Apache licenses.
3. Third-party copyright, patent and notice obligations remain applicable; a future commercial license can cover only rights the licensor actually controls.
4. Do not change root licenses, Cargo/JS package declarations, runtime packaging, README, release tags, main or production metadata during preparation.
5. Do not send any external communications, propose pricing, merge or publish operative terms without explicit approval and legal clearance.
