## Proposed release highlights (private evidence)

- **Background execution fix:** Windows ordinary non-PTY `process.run` now applies Win32 `CREATE_NO_WINDOW` so piped PowerShell children need not flash terminal windows. Deliberate PTY and user-owned terminal behavior is outside this guarantee.
- **Actual Windows verification:** The same private `tetherd-agentw.exe` binary operated on authorized Leno and Surface, each reporting authenticated `device.status`, `ready`, `background_only`. Real non-PTY PowerShell `GetConsoleWindow()` tests returned `NO_CONSOLE_WINDOW` and exit 0 on both.
- **Surface relay recovery:** The old agent was using the historic WSS port **10000**. An independently staged, manually controlled GUI-agent handover updated only the relay port to **443**, preserving the device ID, existing credential reference and authorization boundaries. Only one agent remains, with an established port-443 connection.
- **Startup safeguards staged:** Surface's new Task Scheduler task has a logon trigger, `IgnoreNew`, 3 restart attempts and no execution-time limit. The legacy canary is disabled; a one-time obsolete rollback with `StartWhenAvailable` was disabled after exporting its XML. **No automatic sign-in, reboot, sleep/resume or rollback failover has been independently accepted yet**.
- **Security restrictions preserved:** No Windows security or PowerShell execution-policy bypass, device re-pairing, new OAuth/DCR client or scope broadening. Restricted `device.help` continues returning `permission_denied`.

## Supported assertions / unsupported assertions

- **Demonstrated:** Same hash deployed to two owner-approved Windows PCs; one responsive agent per device; authenticated transport; actual windowless non-PTY commands; preservation of existing identity/scopes and a specific deny boundary.
- **Not demonstrated:** Repeatable clean install by new users, real restart/reboot/sleep recovery, all four machines online simultaneously, production signing/reputation validation, automatic rollback after failure, trusted browser host, approved logo displayed in an installed client, commercial uptake.
- **Windows platform distinction:** Surface runs **Windows 10** build `19045`, where Smart App Control is not available; unsigned PowerShell scripts were rejected by an enforced script-signing policy. Leno runs **Windows 11** build `26300`; the candidate executable's signature is `NotSigned`. The precise Smart App Control mode on Leno has **not** been independently established. Running the candidate must not be called a universal Smart App Control pass. [Microsoft Windows Security reference](https://support.microsoft.com/en-us/windows/security/windows-security/app-browser-control-in-the-windows-security-app).
- **Browser:** Not accepted in this candidate; do not advertise browser operation as live.
- **Logo:** The owner approved **four monochrome source images**. A proposed icon bundle is not yet integrated or verified in a real host. No public branded installer is approved.
