GETTING CONNECTED

Start with what you already have.

  1. 01
    Run locally

    Start Control Center with your existing relay address. Open the local URL printed by the service.

  2. 02
    Use existing access

    Enter a relay client access credential with the account binding and scopes your relay already requires.

  3. 03
    Manage deliberately

    Approve a code from your device, refresh pairing records, or revoke relay access after confirming the device ID.

After a connection interruption, the running device agent retries its existing outbound connection. Refresh here to check pairing records; this does not restart the agent or prove connectivity. After revocation, generate a fresh credential and pairing code on the authorized device through your established setup workflow, then approve the new code here. Keep its existing background-only policy in place.
