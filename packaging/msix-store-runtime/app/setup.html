Optional — connect an owner-approved browser extension

First load Tetherplane's packaged unpacked extension using your browser's extension manager. Confirm its actual ID. Browser access is off until you explicitly enroll this ID, pair the local extension and approve individual tabs and origins. Other tabs remain private.

After enrollment, restart the approved agent and choose Start browser host. Pair the extension locally using its protected owner-only launch token. No browser grants are created by this setup step.

Revocation permanently disables the existing browser enrollment until an explicit owner recovery procedure. Core device pairing is retained.

Optional — reconnect after Windows sign-in

After the device owner has verified an authenticated device.status, open Windows Settings > Apps > Startup and enable Tetherplane Agent. Startup is disabled by default and never starts without the existing approved identity. Windows lets you turn it off at any time. This applies after sign-in, not before login. Do not disable Windows security or create a second Tetherplane task.

A started process is not proof that the relay accepted it. Confirm authenticated device.status independently before trusting a connection.
