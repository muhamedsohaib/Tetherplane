One click connects the extension and shares only this tab for 5 minutes. It uses your existing signed-in browser session. No other tabs are shared.

A separate site-wide grant allows Tetherplane to create new tabs on the selected website. It never authorizes other websites.

Connection troubleshooting

Use local pairing only if the one-click connection does not recover. A completed pairing does not need to be repeated.

Advanced manual pairing
